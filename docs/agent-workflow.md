# Работа агентов

Общий источник — AGENTS.md и применимые вложенные инструкции. Канонический каталог skills — .agents/skills; Claude и OpenCode должны использовать относительные ссылки на него. До завершения переноса проектные процедуры доступны в .opencode/skills.

Основной Codex: gpt-6.1-sol, reasoning medium. Он отвечает за архитектуру, задачи, интеграцию, проверку результатов субагентов, тесты и итоговый результат. Субагенты: gpt-6-luna, reasoning high; максимум 2 одновременно, вложенные субагенты запрещены. Контракт задачи включает цель, типы данных, инварианты, ограничения, граничные значения, область изменения и критерии результата. Предположения явно отделяются от требований. Пересекающиеся изменения выполняются последовательно. DeepSeek, GLM и динамический маршрутизатор не добавляются.

Рекомендуемый локальный фрагмент Codex config (применяет пользователь; глобальные настройки и sol.config.toml агент не меняет):

```toml
model = "gpt-6.1-sol"
model_reasoning_effort = "medium"

[agents]
default_subagent_model = "gpt-6-luna"
default_subagent_reasoning_effort = "high"
max_concurrent_threads_per_session = 2
```

Это рекомендуемые настройки; фактическая поддержка зависит от установленной версии Codex и провайдера. Они не меняют модель уже работающей сессии.

Claude review обязателен для архитектуры, business logic, API, DB, безопасности, matching и агентной инфраструктуры. Для тривиальных локальных/documentation изменений достаточно проверок Codex с указанием причины. Обычный review: Haiku 5.5 после проверки точного model ID; критичный: Sonnet 5.5 после такой же проверки. Не угадывай ID и не подменяй модель молча. При недоступности сообщи ограничение и продолжай остальные задачи.

После Apply и проверок передай reviewer только относящиеся к задаче файлы, OpenSpec и фактически выполненные проверки. Новые файлы включай явно: git diff их не показывает. Пример для проверенного MODEL_ID:

```sh
claude --print --model "$MODEL_ID" --permission-mode plan \
  --tools Read,Grep,Glob --disallowedTools Bash,PowerShell,Edit,Write,NotebookEdit,Agent \
  --strict-mcp-config --mcp-config '{"mcpServers":{}}' \
  --settings '{"useAutoModeDuringPlan":false,"disableAllHooks":true}' \
  --permission-prompts none 'Проведи независимый review указанного scope. Ничего не изменяй.'
```

Сверь флаги с help установленной версии. Не предоставляй инструменты записи, shell или ненужные MCP. Не используй --dangerously-skip-permissions. Plan mode не является изоляцией чтения. Auto Memory сохраняется; не используй --bare/--safe-mode, не устанавливай Claude-Mem и не меняй ~/.claude/settings.json.

Отчёт: findings по severity; для каждого файл/строка, сценарий, влияние и минимальное исправление; отдельно выполненные и пропущенные проверки, ограничения и вердикт. Подтверждённые дефекты отличай от гипотез. Codex проверяет findings, исправляет в scope, повторяет затронутые проверки и review изменённой реализации. Недоступность review не выдаётся за успешный результат.

Proposal сам по себе не разрешает Apply. В текущем change Apply явно разрешён пользователем. Archive выполняется отдельным действием после проверки. Commit/push не выполняются автоматически.
