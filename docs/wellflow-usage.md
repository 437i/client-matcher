# Wellflow Usage Collector

Из корня проекта:

```sh
python3 scripts/wellflow_usage.py
python3 scripts/wellflow_usage.py --from 2026-11-01T00:00:00+03:00 --until 2026-12-01T00:00:00+03:00
python3 -m unittest discover -s tests -p 'test_wellflow_usage.py' -v
```

Collector выполняет реальный запрос только при запуске пользователем. Для ключа используется WELLFLOW_API_KEY из environment; если переменной нет — OPENAI_API_KEY из CODEX_HOME/auth.json, иначе ~/.codex/auth.json. Ключ не передаётся аргументом командной строки и не печатается. Не вставляй ключи в файлы проекта или shell history.

История обходится полностью с limit=20 и cursor до next_cursor=null. Timeout — 30 секунд на попытку; для сетевых ошибок, 429 и 5xx максимум 3 попытки на страницу, Retry-After ограничен 30 секундами. 401/403, невалидный JSON/schema и повтор cursor прекращают сбор. Redirect отклоняется.

Каждый успешный полный обход создаёт отдельный атомарный snapshot в ~/Library/Application Support/client-matcher/wellflow-usage/. На macOS каталог имеет права 0700, файлы — 0600. Не добавляй snapshots в Git. Ошибка обхода не публикует snapshot; уже сохранённые snapshots не изменяются.

Фильтр времени применяется только к сводке: начало включительно, конец исключительно; обязательна timezone. Snapshot содержит полную полученную историю. Стоимость агрегируется по модели через Decimal. В JSON дробные числа сохраняются строками с точным значением, без преобразования в float. Дубликаты сохраняются.

Отчёт показывает исходные cost_cents. Единицу измерения нужно вручную сверить с интерфейсом Wellflow до конвертации в доллары. Не складывай перекрывающиеся snapshots. Collector не придумывает request_id, не приписывает расходы задачам и не предполагает наличие cache breakdown. Без реального запуска совместимость фактического API остаётся непроверенной; неизвестная структура вызывает явную ошибку.
