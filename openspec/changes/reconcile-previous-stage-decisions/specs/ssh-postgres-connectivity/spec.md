# Spec Delta

## ADDED Requirements

### Requirement: Доступ к хранилищу связей до запуска HTTP

В режиме SSH backend SHALL после успешного Goose Up и до открытия HTTP проверить доступ OD_USER к `apps.client_links` для требуемых операций чтения и вставки связей с аудитом. Проверка SHALL выполняться также при отсутствии ожидающих миграций и SHALL NOT изменять данные или права.

#### Scenario: Ранее мигрированная OD без доступа к связям

- **WHEN** схема `apps` доступна, журнал Goose читается и все версии уже применены, но таблица связей отсутствует либо OD_USER не может прочитать или записать необходимые поля в `apps.client_links`
- **THEN** backend завершает запуск с безопасной ошибкой до открытия HTTP даже при наличии доступной одноимённой таблицы в `public`

#### Scenario: Ранее мигрированная OD исправна

- **WHEN** обе БД доступны, Goose Up успешен и OD_USER имеет необходимые права на `apps.client_links`
- **THEN** проверка проходит без пробной записи и backend продолжает штатный запуск HTTP
